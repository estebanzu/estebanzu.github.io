# Esteban Zúñiga — Portfolio

Source repository for [estebanzu.github.io](https://estebanzu.github.io).

Personal website and portfolio of Esteban Zúñiga, Senior Manager, NA Professional Services & Operations at Wind River Systems.

## Tech Stack

- **Framework**: [Jekyll](https://jekyllrb.com/) with [al-folio](https://github.com/alshedivat/al-folio) v1.x
- **Hosting**: [GitHub Pages](https://pages.github.com/)
- **Deployment**: Automatic via GitHub Actions on push to `main`

## Local Development

```bash
docker compose up -d
# Site available at http://localhost:8080/
```
